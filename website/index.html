Quick Installation Guide

Run ShadowMind locally on your machine in 3 simple steps.

01

Clone & Setup

Clone the repository and create your Python virtual environment:

git clone https://github.com/Sourya-Dey05/Shadowmind.git
cd Shadowmind
python -m venv .venv
.venv\Scripts\activate
02

Install Dependencies

Install the required packages and PyTorch binaries:

pip install -r requirements.txt
pip install torch
03

Launch Software

Start the CustomTkinter desktop interface and log in:

python main.py
